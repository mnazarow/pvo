# ПВО-1К «Комар» 🦟🎯

Поворотная «радарная» турель на Arduino по мотивам вирусного видео «ПВО от комаров»: ультразвуковой датчик сканирует сектор, при обнаружении цели турель захватывает её, наводит лазер-целеуказатель и сопровождает. Каждая «поражённая» цель заносится в журнал (Serial).

> Честное ограничение: HC-SR04 комара не увидит — он обнаруживает крупные цели (рука, человек, кот) с ~2–60 см уверенно. Инженер из видео использовал автомобильный mmWave-радар. Наша версия воспроизводит поведение системы, а не её ТТХ. Путь апгрейда — внизу.

## Схема подключения

| Модуль | Контакт модуля | Arduino |
|---|---|---|
| HC-SR04 | VCC | 5V |
| HC-SR04 | GND | GND |
| HC-SR04 | TRIG | D3 |
| HC-SR04 | ECHO | D2 |
| Серво | сигнал (оранжевый) | D9 |
| Серво | + (красный) | 5V (лучше внешний БП 5 В) |
| Серво | − (коричневый) | GND |
| KY-008 | S | D7 |
| KY-008 | − | GND |
| Буззер | + | D8 |
| Буззер | − | GND |

Важно про питание: серво под нагрузкой даёт броски тока — от USB-питания плата может перезагружаться, а серво дёргаться. Лучше питать серво от отдельного источника 5 В (земли обязательно объединить) или хотя бы поставить конденсатор 470–1000 мкФ по питанию серво.

## Механика

HC-SR04 и лазер крепятся **на качалку серво** жёстко и смотрят строго в одну сторону (термоклей / кронштейн из набора / напечатанный pan-кронштейн). Сама серво — на неподвижном основании. Датчик — «глаза», лазер — «ствол»: куда повернулась турель, туда смотрят оба.

## Прошивка

1. Открой `pvo.ino` в Arduino IDE (папка проекта должна называться `pvo` — уже так и есть).
2. Инструменты → Плата: *Arduino Uno* (или *Nano*; для Nano с AliExpress часто нужен процессор *ATmega328P (Old Bootloader)*).
3. Выбери порт, загрузи.
4. Открой Монитор порта, скорость **9600** — увидишь лог: захваты, поражения, журнал.

## Как это работает

Конечный автомат из двух состояний. **ПАТРУЛЬ**: серво шагает по сектору 15–165°, на каждом шаге — замер дистанции; цель ближе 60 см три замера подряд → захват. **СОПРОВОЖДЕНИЕ**: лазер включён, турель качается ±5° вокруг цели и переносит точку удержания туда, где цель видна — так она «ведёт» движущуюся цель; 3 секунды удержания → «цель поражена», +1 в журнал; 12 пустых замеров подряд → цель потеряна, лазер гаснет, патруль продолжается.

Все пороги — константами в начале скетча (`DETECT_DIST_CM`, `SWEEP_MIN/MAX`, `KILL_HOLD_MS`...). Крутить их — половина удовольствия.

## Зелёный экран радара на ПК (опционально)

В скетче поставь `#define RADAR_GUI 1` — телеметрия пойдёт в формате `угол,дистанция.`, который понимает классический Processing-радар (проект «Arduino Radar» с howtomechatronics.com: скачай Processing, возьми их скетч визуализации, укажи свой COM-порт). Получится настоящий экран кругового обзора, как в фильмах.

## ⚠️ Безопасность лазера

Лазер, способный реально жечь насекомых, — это класс 3B/4: **мгновенное необратимое повреждение сетчатки**, в том числе отражённым лучом. В этом проекте лазер — только целеуказатель ≤5 мВт (обычный KY-008). Не ставь турель на уровне глаз, не направляй в сторону людей и животных с близкого расстояния, не заменяй модуль на более мощный.

## Путь апгрейда (ближе к видео)

1. **mmWave-радар RD-03D или HLK-LD2450** (~500–800 ₽): выдаёт X/Y-координаты до 3 движущихся целей по UART на 256000 бод — сканировать серво уже не нужно, турель наводится мгновенно. Для этого лучше взять **ESP32** (несколько аппаратных UART; Uno на такой скорости с SoftwareSerial не справится).
2. **Камера + OpenCV** (Raspberry Pi / ПК): трекинг мелких объектов по видео, Arduino только рулит серво по координатам с последовательного порта. Это единственный реалистичный путь «увидеть» комара.
3. Вторая серво (наклон) — полноценная pan-tilt турель; с HC-SR04 угол места измерить нельзя, но с камерой — можно.
