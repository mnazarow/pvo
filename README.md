# ПВО от комаров 🦟🎯 — карта проекта

Поворотная турель с лазером-целеуказателем по мотивам вирусного видео. Три варианта исполнения, у каждого — свой код и своё руководство по сборке.

## Какой файл к какому варианту

| Вариант | Железо | Код | Руководство по сборке |
|---|---|---|---|
| **A «Часовой»** | Uno/Nano + HC-SR04 + 1 серво | `pvo_a_simple/pvo_a_simple.ino` (минимальный) или `pvo.ino` (полный) | `Сборка_вариант_A.docx` |
| **B «Комар-М»** — как в видео | ESP32 + радар LD2450/RD-03D + pan-tilt | `pvo_esp32/pvo_esp32.ino` | `Сборка_вариант_B.docx` |
| **C «Комар-В»** — зрение | Raspberry Pi + камера + турель A | `pvo_vision.py` (на Pi) + `pvo.ino` (в турели) | `Сборка_вариант_C.docx` |

## Общие файлы

- **`ПВО_от_комаров_руководство.docx`** — главный документ: методология, выбор компонентов, программирование, подробное описание **каждого** параметра с примерами, GUI-пульт, эксплуатация, диагностика, замены компонентов.
- **`pvo_gui.py`** — «Пульт ПВО»: приложение для Windows/macOS (Python + pyserial). Живой радарный экран, настройка всех параметров без перепрошивки, ручное управление, консоль. Запуск: `pip install pyserial`, затем `python pvo_gui.py`.
- **`ПВО_список_покупок.xlsx`** — чеклист закупки с ценами и итогами по конфигурациям.

## Быстрый старт (вариант A за вечер)

1. Купите по разделам 1–3 чеклиста (~2200 ₽).
2. Соберите по `Сборка_вариант_A.docx` (схема + 5 шагов).
3. Прошейте `pvo.ino` (Arduino IDE, плата Uno/Nano, порт 9600).
4. Самотест пройдёт сам; поднесите руку — захват, лазер, «поражение» в журнал.
5. Тонкая настройка — из `pvo_gui.py` (вкладка «Параметры», кнопка W сохраняет в плату).

## Демо и тесты — железо не нужно

- В пульте (`pvo_gui.py`) выберите порт **«ДЕМО: Uno»** или **«ДЕМО: ESP32»** — подключитесь к встроенной виртуальной турели: живой радар, параметры, журнал. Идеально, пока посылка едет.
- `bash tests/run_tests.sh` — автотесты всего проекта: обе прошивки компилируются и гоняются по сценариям на заглушках Arduino API (g++), плюс тесты зрения и GUI. Подробности — `tests/README.md`.
- Каждое «поражение» пульт пишет в журнал с временем и координатами; кнопка «Сохранить CSV…» выгружает статистику для Excel. Вариант C с ключом `--save-hits` дополнительно сохраняет кадры захватов в `hits/`.

## Опциональные модули (включаются одним `#define`, глава 12 руководства)

- **Веб-панель по Wi-Fi** (вариант B, включена по умолчанию): турель раздаёт сеть `PVO-Komar`, радар и все параметры — в браузере телефона на `http://192.168.4.1`. Смените пароль в скетче!
- **OLED SSD1306** (`USE_OLED 1`): экран статуса прямо на турели (SDA=21, SCL=22).
- **Озвучка DFPlayer Mini** (`USE_DFPLAYER 1`): «Цель захвачена» вашим голосом; дорожки `/mp3/0001..0005.mp3`, библиотека не нужна.
- **Telegram** (вариант C): `PVO_TG_TOKEN`/`PVO_TG_CHAT` — уведомления о захватах с фотокадром.
- **3D-печать** (`3d/`): параметрический pan-tilt кронштейн и основание — .scad + готовые STL + превью.

## Протокол (для своих скриптов)

Текстовые строки + `\n`. Uno 9600: `P<угол>` `R` `?` `G` `S ИМЯ ЗНАЧ` `W` `D` `M1/M0`. ESP32 115200: `?` `C` `L1/L0` `T` `G` `S …` `W` `D` `M1/M0`. Подробно — руководство, разделы 3.9 и 4.5.

## Безопасность

Лазер — только ≤5 мВт (KY-008). Автонаводящийся лазер мощнее — это травма зрения, а не игрушка. Не ставьте турель на уровне глаз.
