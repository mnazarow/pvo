# ПВО от комаров 🦟🎯 — карта проекта

Поворотная турель с лазером-целеуказателем по мотивам вирусного видео. Четыре варианта исполнения, у каждого — свой код и своё руководство по сборке.

## Какой файл к какому варианту

| Вариант | Железо | Код | Руководство по сборке |
|---|---|---|---|
| **A «Часовой»** | Uno/Nano + HC-SR04 + 1 серво | `pvo_a_simple/pvo_a_simple.ino` (минимальный) или `pvo.ino` (полный) | `Сборка_вариант_A.docx` |
| **B «Комар-М»** — как в видео | ESP32 + радар LD2450/RD-03D + pan-tilt | `pvo_esp32/pvo_esp32.ino` | `Сборка_вариант_B.docx` |
| **C «Комар-В»** — зрение | Raspberry Pi + камера + турель A | `pvo_vision.py` (на Pi) + `pvo.ino` (в турели) | `Сборка_вариант_C.docx` |
| **D «Комар-Ф»** — слияние | турель B + камера на ней (без ИК-фильтра) + ИК-подсветка | `pvo_fusion.py` (на Pi, рядом кладётся `pvo_vision.py`) + `pvo_esp32.ino` | `Сборка_вариант_D.docx` |

## Общие файлы

- **`ПВО_от_комаров_руководство.docx`** — главный документ: методология, выбор компонентов, программирование, подробное описание **каждого** параметра с примерами, GUI-пульт, эксплуатация, диагностика, замены компонентов.
- **`pvo_gui.py`** — «Пульт ПВО»: приложение для Windows/macOS (Python + pyserial). Живой радарный экран, настройка всех параметров без перепрошивки, ручное управление, консоль. Запуск: `pip install pyserial`, затем `python pvo_gui.py`.
- **`ПВО_список_покупок.xlsx`** — чеклист закупки с ценами и итогами по конфигурациям.
- **`ПВО_шпаргалка_А4.pdf`** — одна страница со всеми командами, параметрами, распиновками и «первой помощью». Распечатать и держать у верстака.
- **`systemd/`** — готовые файлы служб для Raspberry Pi: `pvo.service` (вариант C) и `pvo-fusion.service` (вариант D).

## Быстрый старт (вариант A за вечер)

1. Купите по разделам 1–3 чеклиста (~2200 ₽).
2. Соберите по `Сборка_вариант_A.docx` (схема + 5 шагов).
3. Прошейте `pvo.ino` (Arduino IDE, плата Uno/Nano, порт 9600).
4. Самотест пройдёт сам; поднесите руку — захват, лазер, «поражение» в журнал.
5. Тонкая настройка — из `pvo_gui.py` (вкладка «Параметры», кнопка W сохраняет в плату).

## Демо и тесты — железо не нужно

- В пульте (`pvo_gui.py`) выберите порт **«ДЕМО: Uno»** или **«ДЕМО: ESP32»** — подключитесь к встроенной виртуальной турели: живой радар, параметры, журнал. Идеально, пока посылка едет.
- **Эмулятор AVR**: `bash tests/avr/run_scenarios.sh` — настоящая прошивка, собранная `avr-gcc`, исполняется по тактам (avr8js, движок Wokwi): видно размер во flash/RAM, реальные тайминги и EEPROM, переживающую перезагрузку. Установка: `sudo apt install gcc-avr avr-libc arduino-core-avr` и `(cd tests/avr/js && npm install)`.
- `bash tests/run_tests.sh` — автотесты всего проекта (для GitHub готов workflow: `tests/github-workflow-tests.yml` → скопировать в `.github/workflows/`): обе прошивки компилируются и гоняются по сценариям на заглушках Arduino API (g++), плюс тесты зрения и GUI. Подробности — `tests/README.md`.
- Каждое «поражение» пульт пишет в журнал с временем и координатами; кнопка «Сохранить CSV…» выгружает статистику для Excel. Вариант C с ключом `--save-hits` дополнительно сохраняет кадры захватов в `hits/`.

## Опциональные модули (включаются одним `#define`, глава 12 руководства)

- **Веб-панель по Wi-Fi** (вариант B, включена по умолчанию): турель раздаёт сеть `PVO-Komar`, радар и все параметры — в браузере телефона на `http://192.168.4.1`. Смените пароль в скетче!
- **OLED SSD1306** (`USE_OLED 1`): экран статуса прямо на турели (SDA=21, SCL=22).
- **Озвучка DFPlayer Mini** (`USE_DFPLAYER 1`): «Цель захвачена» вашим голосом; дорожки `/mp3/0001..0005.mp3`, библиотека не нужна.
- **Telegram** (варианты C и D): `PVO_TG_TOKEN`/`PVO_TG_CHAT` — уведомления о захватах с фотокадром.
- **Слияние радара и зрения** (вариант D, глава 13): радар будит зрение и грубо доворачивает турель, камера на турели ведёт цель с точностью 0,1°; ИК-подсветка (GPIO18) открывает охоту на мелочь, которую радар не видит. Запуск: `python3 pvo_fusion.py --detector bright`.
- **Пристрелка лазера** (вариант D): `python3 pvo_fusion.py --calibrate` — скрипт зажигает лазер, находит его точку в кадре и целится потом именно в неё, а не в центр кадра. Без этого шага система стабильно мажет на величину смещения камеры от лазера.
- **Предохранитель сопровождения** (обе прошивки): `TRACKMAX` (по умолчанию 60 с) не даёт турели вести одну «цель» бесконечно — штору на сквозняке или вентилятор. По лимиту лазер и ИК гаснут, турель берёт паузу `TRACKCD`.
- **3D-печать** (`3d/`): параметрический pan-tilt кронштейн, основание варианта A и держатель камеры с кольцом ИК-диодов (вариант D) — .scad + готовые STL + превью.

## Протокол (для своих скриптов)

Текстовые строки + `\n`. Uno 9600: `P<угол>` `R` `?` `G` `S ИМЯ ЗНАЧ` `W` `D` `Z` `M1/M0`. ESP32 115200: `?` `C` `L1/L0` `T` `G` `S …` `W` `D` `Z` `M1/M0` + `V dP dT` (поправка зрения, десятые градуса) и `I1/I0` (ИК) для варианта D. Подробно — руководство, разделы 3.9, 4.5 и глава 13. Версия прошивок печатается при старте и в статусе.

## Безопасность

Лазер — только ≤5 мВт (KY-008). Автонаводящийся лазер мощнее — это травма зрения, а не игрушка. Не ставьте турель на уровне глаз. ИК-подсветка в варианте D — только рассеянные светодиоды, никаких ИК-лазеров: инфракрасный луч невидим, и моргательный рефлекс глаз не защищает.
