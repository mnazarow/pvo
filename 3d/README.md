# 3D-печать для «ПВО от комаров»

Параметрические модели OpenSCAD + готовые STL. Перед печатью **замерьте свои серво штангенциркулем** — у клонов SG90/MG90S размеры гуляют на ±0,5 мм; параметры правятся в начале каждого .scad (бесплатный редактор: openscad.org).

## Файлы

| Файл | Что это | STL |
|---|---|---|
| `pvo_pan_tilt.scad` | кронштейн pan-tilt для варианта B: плита с окном PAN-серво, Г-скоба на качалку с окном TILT-серво, площадка радара и лазера с прорезями под стяжки | `stl/pan_tilt_base.stl`, `stl/pan_tilt_bracket.stl`, `stl/pan_tilt_plate.stl` |
| `pvo_base_a.scad` | основание варианта A: окно серво + поле отверстий (шаг 10 мм) под Arduino/макетку на стяжках | `stl/base_a.stl` |

Превью: `preview_pan_tilt.png`, `preview_base_a.png`.

## Печать

PLA или PETG · слой 0,2 мм · 3 периметра · заполнение 25% · все детали печатаются плашмя, поддержки не нужны. Отверстия под саморезы 2 мм и стяжки уже в моделях; если саморез идёт туго — пройдите отверстие сверлом 2 мм.

## Сборка pan-tilt

1. Плиту (base) — на основание, серво PAN в окно ушами вниз, прикрутить саморезами из комплекта серво.
2. Скобу (bracket) подошвой на круглую крестовину качалки PAN (4 самореза M2 по кругу).
3. Серво TILT — в окно стенки скобы, качалкой наружу.
4. Площадку (plate) — отверстиями на крестовину качалки TILT.
5. Радар и лазер — стяжками в прорези площадки (радар излучателем вперёд, лазер параллельно).
6. Только после прошивки и команды «C» (серво в центры) окончательно затянуть винты качалок «прямо и в горизонт».

Регенерация STL из командной строки:
```bash
openscad -o stl/pan_tilt_base.stl -D 'part="base"' pvo_pan_tilt.scad
openscad -o stl/pan_tilt_bracket.stl -D 'part="bracket"' pvo_pan_tilt.scad
openscad -o stl/pan_tilt_plate.stl -D 'part="plate"' pvo_pan_tilt.scad
openscad -o stl/base_a.stl pvo_base_a.scad
```
